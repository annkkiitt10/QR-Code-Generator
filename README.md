# 📱 QR Code Generator

A simple, modern and responsive **QR Code Generator** built using HTML, CSS and JavaScript.

The application allows users to enter text or a URL and instantly generate a QR code.

## ✨ Features

- 🔗 Generate QR codes from URLs
- 📝 Generate QR codes from text
- ⚡ Instant QR code generation
- 📥 Download QR code
- 🧹 Clear input and reset QR code
- ✨ Modern and attractive interface
- 📱 Responsive design
- 💻 Works on desktop and mobile
- 🎨 Smooth UI animations

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript
- QR Code API/Library
